<h2 class="bar" style="margin-top:48px">Reflections (STAR method)</h2>

<div class="grid grid--2" markdown="1">

<div class="card" markdown="1">
### 1. Coding in Markdown
**Situation:** I was required to create a digital portfolio using GitHub and Markdown.

**Task:** I needed to structure and present my CV and portfolio content professionally using Markdown.

**Action:** I learned how to use headings, lists and formatting tools in Markdown to organise my information clearly and effectively.

**Result:** I improved my documentation skills and gained the ability to present technical information in a clean and professional format.
</div>

<div class="card" markdown="1">
### 2. The mock interview
**Situation:** I participated in a mock interview to prepare for real-world job opportunities.

**Task:** I needed to communicate clearly, answer questions confidently and present myself professionally.

**Action:** I practised answering common interview questions, focused on my communication skills and reviewed my performance afterwards.

**Result:** I became more confident in interviews and improved my ability to present my skills and experience effectively.
</div>

<div class="card" markdown="1">
### 3. GitHub Pages
**Situation:** I needed to publish my portfolio online using GitHub Pages.

**Task:** I had to deploy my portfolio so that it is accessible through a live link.

**Action:** I configured my repository, enabled GitHub Pages and made sure my site was properly structured and working.

**Result:** I deployed my portfolio and gained practical experience in hosting and sharing web content online.
</div>
